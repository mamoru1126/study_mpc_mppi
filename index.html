要点

  • MPC も MPPI も、「少し先までの動きを予測し、いちばん良い入力の列を選び、最初の 1 手だけ実行する」をくり返す。違うのはいちばん良い入力の列の探し方だけ。
  • MPC（この資料では勾配を使う MPC）は、コストの傾き（微分）を計算して、良くなる向きへ入力列を少しずつ直す。直し方の代表がガウス・ニュートン法と SQP。少ない計算で正確に答えに近づき、制約も守れる。ただし、微分できないコストと局所解（近くにある、そこそこの答え）に弱い。
  • MPPI は、入力列にランダムなゆらぎを加えたものをたくさん試し、コストが低いものほど大きな重みをつけて平均する。微分がいらず、どんなコストでも使える。その代わり、たくさん試す必要があり、出力がガタつきやすい。
  • 試す数を十分に増やすと、MPPI の平均は「コストをぼかした地形の坂を下る」更新と同じになる。2 つの方法は、同じ坂下りを、微分で計算するか、試して推定するかの違いと見られる。
  • \(\lambda\) は「どれくらいのコスト差を大きな差とみなすか」を決める目盛り。Nav2 では temperature という名前のパラメータになっている。

共通の最適制御問題

ひとことで今の状態から \(N\) ステップ先までの入力列を決めて、コストの合計を最小にする。この問題を毎周期、解き直す。

ロボットの動きを離散時間のモデル \(x_{t+1} = f(x_t, u_t)\) で表す（\(x\) は状態、\(u\) は入力）。各制御周期で、次の有限ホライズン最適制御問題（OCP）を解く。

\[ \begin{aligned} \min_{u_0, \dots, u_{N-1}} \quad & J = \phi(x_N) + \sum_{t=0}^{N-1} \ell(x_t, u_t) \\ \text{s.t.} \quad & x_{t+1} = f(x_t, u_t), \quad x_0 = \hat x, \\ & u_t \in \mathcal U, \quad h(x_t, u_t) \le 0 \end{aligned} \]
  • \(\ell(x_t, u_t)\)：各時刻の悪さ（目標からのずれ、入力の大きさなど）。\(\phi(x_N)\) は最後の時刻の悪さ。
  • \(x_{t+1} = f(x_t, u_t)\)：モデル。入力列を決めれば、今の状態 \(\hat x\) から未来の状態が順に決まる。
  • \(u_t \in \mathcal U\)、\(h \le 0\)：入力の上限や、「人に近づかない」などの制約。

求めた入力列のうち最初の \(u_0^*\) だけを実行し、次の周期は状態を測り直して解き直す（receding horizon）。前回の答えを 1 ステップずらしたものを、次の計算の出発点にする（ウォームスタート）。ここまでは MPC も MPPI も同じだ。

例：差動 2 輪

\[ x = \begin{bmatrix} p_x \\ p_y \\ \theta \end{bmatrix}, \quad u = \begin{bmatrix} v \\ \omega \end{bmatrix}, \quad f(x, u) = x + \Delta t \begin{bmatrix} v \cos\theta \\ v \sin\theta \\ \omega \end{bmatrix} \]

\(\Delta t\) 秒で、向き \(\theta\) の方向に \(v\,\Delta t\) 進み、\(\omega\,\Delta t\) だけ回る、というモデルだ。デモのコストは、両方の手法で同じ次の式にした。

\[ \begin{aligned} \ell(x_t, u_t) &= \|p_t - p_t^{\mathrm{ref}}\|^2 + q_\omega\, \omega_t^2 + q_o \textstyle\sum_i \max\big(0,\ d_{\mathrm s} - \|p_t - o_{i,t}\|\big)^2 \\ \phi(x_N) &= q_N\, \|p_N - p_N^{\mathrm{ref}}\|^2 \end{aligned} \]
  • 第 1 項：目標点 \(p_t^{\mathrm{ref}}\)（ゴールへ向かう直線上を一定速度で進む点）からのずれ。
  • 第 2 項：回りすぎを抑える。
  • 第 3 項：人 \(i\) の予測位置 \(o_{i,t}\) から距離 \(d_{\mathrm s}\) より内側に入ると、入った深さの 2 乗に比例する罰。外にいれば 0。

定式化の対比

ひとことでMPC は「1 本の入力列」を直接最適化する。MPPI は「入力列のばらつき（確率分布）」を考えて、その平均を最適化する。

MPC：1 本の入力列を最適化

変数は入力列 \(U = (u_0, \dots, u_{N-1})\) そのもの。

線形・2 次（LQ）の場合

\[ \begin{aligned} x_{t+1} &= A x_t + B u_t \\ \ell &= x_t^\top Q x_t + u_t^\top R u_t, \quad \phi = x_N^\top P x_N \end{aligned} \]

モデルが線形なので、未来の状態は入力列の 1 次式 \(X = \mathcal A x_0 + \mathcal B U\) で書ける。これを代入すると、コストは \(U\) の 2 次関数になる。

\[ \begin{aligned} J(U) &= U^\top H U + 2\, x_0^\top F^\top U + \text{const} \\ H &= \mathcal B^\top \bar Q \mathcal B + \bar R, \quad F = \mathcal B^\top \bar Q \mathcal A \end{aligned} \]

（\(\bar Q\)、\(\bar R\) は \(Q\)、\(R\) を対角に並べた行列。）2 次関数なので、制約がなければ「微分 = 0」の連立 1 次方程式を解くだけで \(U^* = -H^{-1} F x_0\) と一発で求まる。制約 \(G U \le w + E x_0\) があるときは QP（2 次関数を 1 次の不等式のもとで最小化する問題）になり、専用ソルバー（OSQP など）で速く確実に解ける。

非線形の場合

一発では解けない。今の答えのまわりで線形化して、上の解きやすい形に置きかえて解く、をくり返す（ガウス・ニュートン法、SQP）。

MPPI：入力列の分布の平均を最適化

入力にガウスのゆらぎを加えた \(v_t = u_t + \varepsilon_t\)（\(\varepsilon_t \sim \mathcal N(0, \Sigma)\)）を考え、次の 3 段で平均 \(U\) を決める。

① 理想の分布：良い入力列ほど出やすい

\[ q^*(V) = \frac{1}{\eta}\, p(V)\, e^{-S(V)/\lambda} \]

\(S(V)\) は入力列 \(V\) でロールアウトしたときのコスト、\(p\) は元のばらつき（平均 0 のガウス）、\(\eta\) は合計を 1 にする定数。コストが低い入力列ほど、\(e^{-S/\lambda}\) 倍だけ出やすくなる。

この形が出てくる理由

「平均コストを下げたいが、元のばらつき \(p\) から離れすぎたくない」という問題 \(\min_q \mathbb E_q[S] + \lambda\,\mathrm{KL}(q \,\|\, p)\) の答えがこの形になる。\(\mathrm{KL}(q \,\|\, p)\) は 2 つの分布の違いの大きさで、\(\lambda\) はその 2 つのつり合いを決める。

② 新しい入力列 = 理想の分布の平均

実際に扱えるのは「平均 \(U\) のまわりのガウスのばらつき」だけなので、\(q^*\) にいちばん近いガウスを選ぶ。それは平均を \(q^*\) の平均に合わせたもの、つまり \(U^* = \mathbb E_{q^*}[V]\)。

③ 平均はサンプルの重みつき平均で推定する

\(q^*\) から直接サンプルは引けないので、今の \(U\) のまわりで \(K\) 本引き、重みで補正して平均する（重点サンプリング）。

\[ \begin{aligned} u_t &\leftarrow u_t + \sum_{k=1}^{K} w_k\, \varepsilon_t^k, \qquad w_k = \frac{e^{-\tilde S_k/\lambda}}{\sum_j e^{-\tilde S_j/\lambda}} \\ \tilde S_k &= S(U + E^k) + \lambda \sum_t u_t^\top \Sigma^{-1} \varepsilon_t^k \end{aligned} \]

\(E^k\) は \(k\) 本目のゆらぎの列。\(\tilde S_k\) の最後の項は、ゆらぎを平均 0 ではなく \(U\) のまわりで引いたことの補正で、Nav2 ではこの係数を gamma という別のパラメータにしている。

アルゴリズムの対比

ひとことでどちらも「今の案のまわりを調べる → 改善案を作る → 案を更新する → 最初の 1 手を実行して、案をずらす」という同じ骨組み。違うのは「調べ方」と「改善の仕方」。

NMPC（ガウス・ニュートン / SQP）MPPI
出発点前回の答えを 1 ステップずらしたもの同じ
1. まわりを調べるモデルとコストを微分して、今の案のまわりの「傾き」を求める（\(A_t = \partial f / \partial x\)、\(B_t = \partial f / \partial u\)、ヤコビアン \(J\)）ゆらぎ \(\varepsilon_t^k \sim \mathcal N(0, \Sigma)\) を \(K\) 組引き、まわりを実際に試す準備をする
2. 改善案を作る傾きから作った近似問題（QP や線形最小二乗）を解き、直す量 \(\Delta z\) を求める\(K\) 本をロールアウトして、それぞれのコスト \(\tilde S_k\) を計算する（並列にできる）
3. 更新する\(z \leftarrow z + \alpha \Delta z\)。悪くなるなら歩幅 \(\alpha\) を小さくする重み \(w_k\) でゆらぎを平均し、\(u_t \leftarrow u_t + \sum_k w_k \varepsilon_t^k\)
4. くり返す1〜3 を収束まで。RTI なら 1 周期に 1 回だけ1〜3 を数回。Nav2 の既定は 1 回
出力\(u_0\) を実行して、案をずらす同じ
1 周期の計算微分と QP。時間方向の構造を使えば、ホライズン長に比例する時間で解けるモデルの計算が \(K \times N\) 回。サンプルごとに独立なので並列にできる

NMPC（single shooting、ガウス・ニュートン + LM）

# z = [u_0, ..., u_{N-1}]（前回の答えをずらしたもの）
for it in range(iters):
    X = rollout(x_hat, z)                # 予測
    r, J = residual_and_jacobian(X, z)   # ずれと、その傾き
    H, g = J.T @ J, J.T @ r
    while True:                          # 悪くなったら慎重に
        dz = solve(H + mu * diag(H), -g)
        z_new = clip(z + dz, u_min, u_max)
        if cost(z_new) < cost(z):
            z, mu = z_new, mu / 3
            break
        mu = mu * 4
send(z[0])                               # 最初の 1 手だけ実行
z = shift(z)

MPPI

# U = [u_0, ..., u_{N-1}]（前回の答えをずらしたもの）
eps = normal(0, Sigma, size=(K, N))      # ゆらぎを K 組
S = [cost(rollout(x_hat, U + eps[k]))
     for k in range(K)]                  # 全部試す（並列）
S = S + lam * sum_t(U[t] @ inv(Sigma) @ eps[:, t])
w = exp(-(S - S.min()) / lam)            # 良いものほど重く
w = w / w.sum()
U = U + w @ eps                          # 重みつき平均
U = smooth(U)                            # 任意
send(U[0])                               # 最初の 1 手だけ実行
U = shift(U)

ガウス・ニュートン法

ひとことでずれ（残差）を「入力を少し動かしたときの変化」で直線的に予測し、その予測の上でずれの 2 乗和が最小になる所へ動く。これをくり返す。

残差が 1 つなら：接線で 0 を探す

ずれ \(r(z)\) を 0 にしたいとき、今の点で接線を引き、接線が 0 になる所へ移る。

\[ z \leftarrow z - \frac{r(z)}{r'(z)} \]

たとえば \(r(z) = z^2 - 2\)（答えは \(\sqrt 2 = 1.414214\cdots\)）なら、\(z = 2 \to 1.5 \to 1.41667 \to 1.414216\) と、3 回で小数第 5 位まで合う。

残差が複数なら：近似の 2 乗和を最小にする

MPC では「各時刻の目標とのずれ」「入力の大きさ」など、残差がたくさんある。全部を同時に 0 にはできないので、2 乗和 \(F(z) = \tfrac12 \|r(z)\|^2\) を最小にする。残差を 1 次近似 \(r(z + \Delta) \approx r + J\Delta\) で置きかえ、その 2 乗和が最小になる \(\Delta\) を選ぶと

\[ \Delta = \operatorname*{arg\,min}_{\Delta} \|r + J \Delta\|^2 \quad \Longleftrightarrow \quad J^\top J\, \Delta = -J^\top r \]
  • \(J = \partial r / \partial z\)（ヤコビアン）：各残差が、各変数を少し動かしたときにどれだけ変わるかを並べた表。
  • \(J^\top r\)：コスト \(F\) の勾配（どちらへ動くとずれが増えるか）。
  • \(J^\top J\)：コストの曲がり具合（ヘッセ行列）の近似。曲がりが大きい方向は小さく、ゆるい方向は大きく動く。

本当のヘッセ行列は \(\nabla^2 F = J^\top J + \sum_i r_i \nabla^2 r_i\) で、ニュートン法はこれを使う。ガウス・ニュートン法は第 2 項を捨てるので、2 階微分を計算しなくてよい。残差が小さいとき（答えの近く）や、残差がほぼ直線的なときは、捨てた項が小さく、ニュートン法とほぼ同じ速さで収束する。\(J^\top J\) は必ず半正定値なので、得られる \(\Delta\) は（\(J\) が列フルランクなら）必ずコストを下げる向きを向く。

うまくいかないときは慎重に：LM 法

直線近似が外れる所では、\(\Delta\) が大きすぎてコストが上がることがある。そこで減衰 \(\mu\) を足す。

\[ (J^\top J + \mu D)\, \Delta = -J^\top r, \qquad D = I \ \text{または}\ \mathrm{diag}(J^\top J) \]

\(\mu\) は慎重さのつまみで、大きいと小さな歩幅の勾配法、小さいとガウス・ニュートン法になる。コストが下がったら \(\mu\) を小さくして大胆に、上がったら大きくして慎重にする（Levenberg–Marquardt 法）。

方法ステップ必要なもの収束の速さ（答えの近く）
最急降下法\(\Delta = -\alpha J^\top r\)1 階微分遅い（1 次）
ガウス・ニュートン法\(\Delta = -(J^\top J)^{-1} J^\top r\)1 階微分（\(J\)）残差が 0 に近いほど速い
LM 法\(\Delta = -(J^\top J + \mu D)^{-1} J^\top r\)1 階微分（\(J\)）\(\mu\) で上 2 つの間を動く
ニュートン法\(\Delta = -(\nabla^2 F)^{-1} \nabla F\)2 階微分速い（2 次）

MPC に当てはめる

変数 \(z\) は入力列 \(U\)、残差は「各時刻の目標とのずれ」と「入力の大きさ」に重みの平方根をかけて並べたベクトルにする。

\[ r(U) = \begin{bmatrix} Q^{1/2} (x_1 - x_1^{\mathrm{ref}}) \\ \vdots \\ P^{1/2} (x_N - x_N^{\mathrm{ref}}) \\ R^{1/2} u_0 \\ \vdots \\ R^{1/2} u_{N-1} \end{bmatrix} \]

\(J\) を作るには「入力 \(u_s\) を少し変えると、後の状態 \(x_t\) がどれだけ変わるか」（感度）が要る。\(u_s\) の変化は \(B_s\) で次の状態に伝わり、そこから先は \(A\) をかけながら伝わっていくので、モデルの微分の積で求まる（連鎖律）。

\[ \frac{\partial x_t}{\partial u_s} = A_{t-1} A_{t-2} \cdots A_{s+1} B_s \quad (s < t), \qquad A_t = \frac{\partial f}{\partial x}, \quad B_t = \frac{\partial f}{\partial u} \]

差動 2 輪では次のようになる。

\[ A_t = \begin{bmatrix} 1 & 0 & -v_t \sin\theta_t\, \Delta t \\ 0 & 1 & v_t \cos\theta_t\, \Delta t \\ 0 & 0 & 1 \end{bmatrix}, \qquad B_t = \begin{bmatrix} \cos\theta_t\, \Delta t & 0 \\ \sin\theta_t\, \Delta t & 0 \\ 0 & \Delta t \end{bmatrix} \]

人に近すぎる時刻では、障害物の項 \(\max(0, d_{\mathrm s} - d)\) も残差に加わり、\(J\) には「人から離れる向きに動くと残差が減る」という行が入る。デモの NMPC は、この \(J\) を解析的に組み、LM 法を 1 周期に 3 回（既定）くり返している。

非線形 MPC（NMPC）

ひとことで非線形な問題は一度には解けないので、「今の答えのまわりで近似して、解きやすい QP にして解く」をくり返す（SQP）。ガウス・ニュートン法は、この QP の作り方の 1 つ。

どう変数を置くか：shooting

  • single shooting：変数は入力列だけ。状態はモデルで順に計算する。変数は少ないが、最初のほうの入力が後の状態に大きく効くので、ホライズンが長いと数値的に不安定になりやすい。
  • multiple shooting：区間ごとの始点の状態も変数にし、「区間の終わりと次の始点が一致する」ことを制約にする。最初はつながっていなくてよく、反復しながらつながっていく。安定で、ソルバー（acados など）の標準。

どう解くか：SQP

今の答え \((\bar X, \bar U)\) のまわりで、コストを 2 次で、制約（モデルを含む）を 1 次で近似すると、QP になる。それを解いて直す量 \((\Delta x, \Delta u)\) を求め、答えを更新する、をくり返す。

\[ \begin{aligned} \min_{\Delta x, \Delta u} \quad & \sum_{t} \tfrac12 \begin{bmatrix} \Delta x_t \\ \Delta u_t \end{bmatrix}^{\!\top} \! H_t \begin{bmatrix} \Delta x_t \\ \Delta u_t \end{bmatrix} + \nabla \ell_t^\top \begin{bmatrix} \Delta x_t \\ \Delta u_t \end{bmatrix} \\ \text{s.t.} \quad & \Delta x_0 = \hat x - \bar x_0, \\ & \Delta x_{t+1} = A_t \Delta x_t + B_t \Delta u_t + \big( f(\bar x_t, \bar u_t) - \bar x_{t+1} \big), \\ & g(\bar x_t, \bar u_t) + \nabla g_t^\top \begin{bmatrix} \Delta x_t \\ \Delta u_t \end{bmatrix} \le 0 \end{aligned} \]
  • 1 行目：コストの 2 次近似。\(H_t\) に \(J_t^\top J_t\)（ガウス・ニュートン近似）を使えば、2 階微分なしで、必ず解ける（凸な）QP になる。
  • 2〜3 行目：モデルの線形化。\(f(\bar x_t, \bar u_t) - \bar x_{t+1}\) は multiple shooting のつなぎ目のずれで、これも 0 に向かって直される。
  • 4 行目：制約の線形化。

この QP は時刻ごとのブロックが鎖のようにつながった形をしているので、専用ソルバー（HPIPM など）でホライズン長に比例する時間で解ける。SQP の代わりに、内点法（IPOPT など）で NLP をそのまま解く方法もある。

毎周期 1 回だけ解く：RTI

Real-Time Iteration（RTI）は、制御周期ごとに SQP の改善を 1 回だけ行い、続きは次の周期に持ち越す。前回の答えをずらした出発点はすでに答えに近いので、1 回でも十分に追いつける。さらに、状態を測る前に線形化と QP の準備を済ませておき、測ったら QP を解くだけにして、計算の遅れを小さくする。

人をよける制約と局所解

「人から \(d_{\mathrm s}\) 以上離れる」は、左右どちらからよけてもよいので、答えが 2 つある（凸でない）制約だ。SQP では今の位置で線を引いた半平面に置きかえる。

\[ n_t^\top (p_t - o) \ge d_{\mathrm s}, \qquad n_t = \frac{\bar p_t - o}{\|\bar p_t - o\|} \]

\(n_t\) は、人から今の位置へ向かう単位ベクトル。

だから、どちら側をよけるかは出発点で決まり、反対側のほうが良くてもそちらへは移れない（局所解）。人がちょうど真正面にいると \(n_t\) が進行方向と平行になり、横に動く理由がなくなって手前で止まる。デモの「真正面の人」がこれだ。

実装の例：acados（SQP・RTI、QP は HPIPM）、CasADi と IPOPT（内点法）。

MPPI の \(\lambda\)

ひとことで\(\lambda\) は「コストがどれだけ違えば、重みに大きな差をつけるか」の目盛り。

2 本のサンプルの重みの比は、コストの差だけで決まる。

\[ \frac{w_i}{w_j} = \exp\!\left( -\frac{\tilde S_i - \tilde S_j}{\lambda} \right) \]
\(\lambda\)コストが 1 違うときの重みの比ふるまい
0.10.00005少しの差で大きく変わる。最良の 1 本だけを使うのに近い
10.37差が 1 で重みが \(1/e\) 倍
100.90ほぼ同じ重み。ただの平均に近く、更新が進みにくい

重みがどれだけ集中しているかは、実効サンプル数 \(\mathrm{ESS} = 1 / \sum_k w_k^2\) で見られる。全部同じ重みなら \(K\)、1 本に集中すれば 1 になる。ちょうどよい \(\lambda\) はコストの大きさで変わるので、コストの重みを変えたら \(\lambda\) も調整し直す。

論文や Nav2 で \(\lambda\) が temperature と呼ばれるのは、\(q^* \propto p\, e^{-S/\lambda}\) が、物理のボルツマン分布 \(e^{-E/(k_{\mathrm B} T)}\)（エネルギー \(E\)、温度 \(T\)）と同じ形をしているからで、物理的な意味はない。

2 つの更新の関係

ひとことで試す数を十分に増やすと、MPPI の更新は「コストをガウスでぼかした地形」の坂を下る勾配法と同じになる。2 次コストなら、ガウス・ニュートン（LM）法とまったく同じ形の式になる。

ぼかした地形の坂を下る

MPPI の重みつき平均は、サンプルを無限に増やすと、次の式になる。

\[ \begin{aligned} \Delta u &= -\frac{\Sigma}{\lambda}\, \nabla F_\lambda(\bar u) \\ F_\lambda(\bar u) &= -\lambda \log \mathbb E_{\varepsilon \sim \mathcal N(0, \Sigma)}\!\left[ e^{-S(\bar u + \varepsilon)/\lambda} \right] \end{aligned} \]

\(F_\lambda\) は、今の平均 \(\bar u\) のまわり（幅 \(\Sigma\)）のコストを、良いほうを重視して平均したもの、つまり「コストをぼかした地形」だ。MPPI は、その坂を歩幅 \(\Sigma/\lambda\) で下っている。元のコスト \(S\) が段差でも、ぼかした \(F_\lambda\) はなめらかな坂になるので、段差のコスト（接触したら罰）でも避ける向きに動ける。

導出を見る

\(K \to \infty\) の重みつき平均は \(\Delta u = \mathbb E[\varepsilon\, e^{-S(\bar u+\varepsilon)/\lambda}] \,/\, \mathbb E[e^{-S(\bar u+\varepsilon)/\lambda}]\)。一方、\(G(\bar u) = \mathbb E[e^{-S(\bar u+\varepsilon)/\lambda}] = \int \mathcal N(v; \bar u, \Sigma)\, e^{-S(v)/\lambda} dv\) を \(\bar u\) で微分すると、ガウス密度の微分 \(\nabla_{\bar u} \mathcal N(v; \bar u, \Sigma) = \mathcal N(v; \bar u, \Sigma)\, \Sigma^{-1}(v - \bar u)\) から \(\nabla G = \Sigma^{-1} \mathbb E[\varepsilon\, e^{-S/\lambda}]\)。よって \(\nabla F_\lambda = -\lambda \nabla G / G = -\lambda \Sigma^{-1} \Delta u\) となり、上の式が得られる（Stein の補題）。

2 次コストならガウス・ニュートン（LM）法と同じ形

コストが 2 次関数 \(S(u) = \tfrac12 (u - c)^\top A (u - c)\)（最小点 \(c\)、曲がり具合 \(A\)）なら、重みとガウスの積もガウスになり、更新が閉じた形で書ける。並べると、役割が一対一に対応する。

ガウス・ニュートン・LM

\[ \Delta z = -\left( J^\top J + \mu D \right)^{-1} J^\top r \]

曲がり具合 \(J^\top J\)、勾配 \(J^\top r\)、慎重さ \(\mu D\)。

MPPI（サンプル無限、2 次コスト）

\[ \Delta u = -\left( A + \lambda \Sigma^{-1} \right)^{-1} \nabla S(\bar u) \]

曲がり具合 \(A\)、勾配 \(\nabla S\)、慎重さ \(\lambda \Sigma^{-1}\)。

つまり MPPI は、慎重さの項が \(\lambda \Sigma^{-1}\) の LM 法になっている。\(\lambda\) が小さい（またはゆらぎ \(\Sigma\) が大きい）ほど大胆なニュートン法に近づき、\(\lambda\) が大きいほど歩幅 \(\Sigma/\lambda\) の慎重な勾配法になる。違いは、MPC がこれらを微分で正確に計算するのに対し、MPPI はサンプルで推定するので、サンプルが少ないとノイズが乗ることだ。

得意・苦手の対比

ひとことでMPC は「なめらかなコストで、制約を正確に守りたい問題」に、MPPI は「コストが複雑（段差、地図の参照など）で、計算を並列に回せる問題」に向く。

観点MPC（勾配法・SQP / GN）MPPI
収束と評価回数◎傾きと曲がり具合を使い、数回の反復で収束する（デモでは 1 周期にロールアウト 10 回程度）△\(K\) 本のロールアウトが要る（デモは 300、Nav2 の既定は 1000）。サンプルが有限なので推定誤差が残る
制約◎入力・状態の制約を QP の制約として正確に扱える△入力はクリップ、状態は罰で扱う。守られる保証はない
コストの形×微分できないといけない。「接触したら罰」のような段差は傾きが 0 で効かない◎計算できれば何でもよい（段差、地図の参照など）
局所解×出発点の近くの答えで止まる。真正面の障害物では手前で止まる○ゆらぎで左右の偏りができ、離れた答えにも届く。ただし左右の候補を平均すると、真ん中（ぶつかる側）に寄ることがある
モデル△微分（ヤコビアン）が要る。自動微分で用意することが多い◎中身のわからないモデル（シミュレータ、学習モデル）でもよい

出力のなめらかさ◎乱数を使わないのでなめらか△乱数でガタつく。平滑化や「入力の変化」の罰で抑える
理論◎安定性や、制約を満たし続けられることの理論がある（終端コスト・終端制約を使う）△サンプルが有限のときの最適性や安定性の保証は弱い

デモ：NMPC と MPPI

左が NMPC（ガウス・ニュートン法）、右が MPPI。モデル・コスト・場面は同じで、違うのは解き方だけだ。

  • ずれて立つ人・なめらかな罰：どちらも到着する。NMPC は入力がなめらかで、1 周期の評価回数が 1 桁以上少ない。
  • 真正面の人・なめらかな罰：左右対称で横へ動く理由がなく、NMPC は人の手前で止まる。MPPI はゆらぎで左右の偏りができて回り込む。
  • 接触だけ罰：罰が段差なので傾きが 0 になり、NMPC は人を無視して進んで接触する。MPPI は接触するサンプルの重みがほぼ 0 になるので避ける。
  • MPPI の \(\lambda\) を小さくすると最良の 1 本に引きずられてガタつき、大きくすると更新が進まなくなる。
